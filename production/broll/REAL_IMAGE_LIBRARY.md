## Summary

- 105 raw files enumerated; all genuinely distinct in content (no byte-identical
  duplicates found in this pass — unlike the earlier still-photography build, which
  folded 4 duplicates from a larger raw set that included files outside these five
  prefixes).
- Studio Bridge and Model 24 carry the deepest, most authentic real-world workflow
  photography (official TASCAM diagrams, an actual live tracking session, hand-written
  session labels). Model 12, 16 and 2400 are strong on hero/control/rear-panel detail
  but thinner on documented real-world workflow moments — this directly shapes the
  scenario count per unit in Section 2.
