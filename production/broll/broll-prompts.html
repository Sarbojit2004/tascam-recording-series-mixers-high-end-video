How to run each one

  1. Open a fresh Gemini chat for each clip — don't chain them in one thread, so an earlier reference image can't bleed into a later generation.
  2. Attach the exact file(s) named in that clip's "Attach" row — pull them straight from the repo root (tascam-recording-series-mixers-high-end-video/).
  3. Copy the prompt with the button and paste it as your message alongside the attached image(s). Don't edit it unless something in your own preview looks wrong.
  4. Ask for a 10-second, 16:9 video explicitly if your Gemini video tool exposes a duration/aspect control separately from the prompt text — the wording already states it too, as a fallback.
  5. Save the result as broll-<clip-id>.mp4 (the id is printed in each card's kicker line) and send it back — duration and hardware fidelity get checked against the same reference photos before anything is accepted into the edit.
